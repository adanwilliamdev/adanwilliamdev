COMO ATUALIZAR SEU PERFIL DO GITHUB (versao visual nova)

1. No repositorio adanwilliamdev/adanwilliamdev, SUBSTITUA pelo conteudo desta pasta:
   - README.md
   - assets/ (os nomes mudaram de proposito, para o GitHub nao mostrar a versao antiga em cache; depois de publicar, apague hero.svg, h-*.svg e card-*.svg antigos)
   - .github/workflows/snake.yml
   (apague este arquivo se quiser)
2. Commit na branch main.
3. Aba Actions > "Gerar Snake" > Run workflow (uma vez), para gerar a cobrinha
   com as cores novas (modo claro e escuro).
4. Abra github.com/adanwilliamdev e de um Ctrl+F5. O GitHub guarda imagens em
   cache, entao se algo antigo aparecer, espere alguns minutos.

Via terminal:
  git add .
  git commit -m "feat: novo visual do perfil"
  git push

Para editar textos/cores: tudo que aparece em imagem esta nos SVGs de assets/.
