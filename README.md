## 🚀 Projetos em destaque

### 🎟️ [ticketing-system](https://github.com/adanwilliamdev/ticketing-system)
Sistema de reservas e pagamentos no estilo Ticketmaster, focado em **alta concorrência**: lock pessimista no banco, **lock distribuído com Redisson/Redis**, reserva temporária com expiração automática e **idempotência** em pagamentos.
`Java 21` `Spring Boot` `PostgreSQL` `Redis` `Flyway` `Docker`

### 🧩 [task-management (TaskFlow)](https://github.com/adanwilliamdev/task-management)
Gerenciador de tarefas em **arquitetura de microsserviços**: API Gateway, Service Discovery (Eureka), serviços de auth, usuários, tarefas e notificações, um banco por serviço e JWT validado localmente em cada serviço.
`Java` `Spring Cloud` `Spring Security` `PostgreSQL` `React` `Docker Compose`

### 🛰️ [OrbNOC](https://github.com/adanwilliamdev/OrbNOC)
Plataforma de monitoramento de equipamentos de rede: status em tempo real via WebSocket, latência/jitter/perda de pacotes, alertas, SLA, notificações no Telegram, diagnóstico de rede e relatórios CSV/XLSX.
`Java` `Spring Boot` `Thymeleaf` `Redis` `PostgreSQL` `WebSocket` `Docker`

### 🔧 [Torque_Gestao](https://github.com/adanwilliamdev/Mecanica_Plus)
Sistema de gestão para oficinas: clientes, veículos, mecânicos, estoque, orçamentos e ordens de serviço, com controle de acesso por perfil (admin, gerente, recepção, mecânico) e auditoria de estoque.
`Java` `Spring Boot` `Spring Security` `Docker`

### 🍕 [Burger & Pizza House ERP](https://github.com/adanwilliamdev/Burger-Pizza-House)
ERP para pizzarias e hamburguerias: pedidos com transições de status validadas, baixa automática de estoque em transação atômica, dashboard de faturamento e autenticação segura.
`Java` `Spring Boot` `Spring Security` `Docker`

### 📦 [itau-java-ai-order-system](https://github.com/adanwilliamdev/itau-java-ai-order-system)
API de pedidos construída sobre **4 padrões de projeto** (State, Chain of Responsibility, Strategy e Observer) com **comandos de voz** via Spring AI (transcrição de áudio + identificação de intenção). Desafio final do programa Itaú Java AI (DIO).
`Java 17` `Spring Boot` `Spring AI` `JPA` `Swagger`
